# Hack The Box Writeups

This repository contains my **Hack The Box writeups**, documenting the process followed to solve different machines and challenges.

Each writeup includes the relevant steps, commands, findings, and reasoning used throughout the process, from initial enumeration to gaining the highest level of access.

## Objective

The main objective of this repository is to **document my progress, keep a personal reference of what I learn, and share my solutions to different Hack The Box machines**.

All machines and techniques documented here are intended for **authorized security testing and educational purposes** within Hack The Box laboratories.
